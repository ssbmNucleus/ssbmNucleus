# SSBM Nucleus 0.10.0

- **Unlocked on Windows**. SSBM Nucleus Unlocked is a native Melee client based on Melee
  Unlocked by Hero88go. The app installs client 0.1.0 on first use and keeps it up to date.
  You need your own Melee 1.02 disc image, a processor with AVX2, and app 0.10.0 or later.
- Equip character and stage skins in the in-game mod manager. Opponents see each other's
  skins online. The game downloads them from ssbmnucleus.net and checks them before use. Fighters,
  New Stages, Particles, and Menus are listed as coming soon.
- Play Slippi ranked, unranked, and Direct, join doubles lobbies, or use the built-in
  Training Mode. Direct has an Items option that both players must turn on.
- The Vanilla card starts Melee with nothing changed. Unlocked opens first on a new
  Windows install.
- **Tracker** now shows names and connect codes for online games whose replay metadata had none.

Full changelog: https://github.com/ssbmNucleus/ssbmNucleus/blob/main/CHANGELOG.md
