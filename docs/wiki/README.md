# Melee Modding Wiki

General Melee modding context and Nucleus workflow notes.

## Local Browser View

Run `npm run wiki` from `app/` (it runs `python ../tools/wiki/serve.py`), then open `http://127.0.0.1:4173/wiki/`.

On Windows, you can also run `tools/dev/open_wiki.bat`. It starts the wiki server if needed and opens the wiki in Firefox.
